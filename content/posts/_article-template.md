这里是文章导语。正式文章不需要再写一级标题，页面会自动使用上方的 `title` 生成文章标题。

这是普通段落。可以使用 **粗体强调**、*斜体强调*、~~删除内容~~，也可以插入[文字链接](https://example.com)和 `行内代码`。

## 二级标题

二级标题用于文章的主要章节，也是文章页最常用的标题层级。

### 三级标题

三级标题适合在一个章节中继续拆分内容。

#### 四级标题

四级标题只在内容层级确实复杂时使用，避免为了视觉效果堆叠标题。

> 这是引用段落。适合放置原文摘录、重要判断或者需要与正文区分的补充信息。
>
> 引用中可以包含多个段落。

## 列表

- 第一项内容；
- 第二项内容；
  - 嵌套项目；
- 第三项内容。

有序列表：

1. 第一步；
2. 第二步；
3. 第三步。

任务列表：

- [x] 已完成事项
- [ ] 尚未完成事项

## 代码

行内代码适合表示变量或命令，例如 `npm run dev`。

```ts
interface ArticleMeta {
  title: string
  aiGenerated: boolean
}

const article: ArticleMeta = {
  title: '文章标题',
  aiGenerated: false,
}
```

## 表格

| 项目 | 说明 | 状态 |
| --- | --- | --- |
| 标题 | 文章的主要标题 | 必填 |
| 摘要 | 首页显示的简短介绍 | 必填 |
| AI 标识 | 是否显示 AI 生成标识 | 可选 |

## 发布前检查

1. 将本文件复制并重命名为英文短横线文件名，例如 `my-new-article.md`；
2. 修改标题、摘要、日期、标签和阅读时长；
3. 需要置顶时设置 `pinned: true`，需要精选标识时设置 `featured: true`；
4. AI 生成文章设置 `aiGenerated: true`；
5. 删除不需要的示例章节；
6. 完成后将 `draft` 改为 `false`。
