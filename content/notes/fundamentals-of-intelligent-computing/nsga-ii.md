## 先抓住主线：先比非劣等级，再比拥挤距离

假设设计一个模型，你希望它**误差低**，又希望它**运行快**。模型 A 的误差更低但耗时更长，模型 B 的耗时更短但误差稍大。只问“谁最好”，没有唯一答案：你还没有说愿意用多少时间换多少精度。

NSGA-II（Non-dominated Sorting Genetic Algorithm II）由 Deb 等人在 2002 年提出，是一种带**精英策略**的多目标遗传算法。它维护一批代表不同取舍的候选解，用交叉和变异探索新解，努力让留下的解既接近 Pareto 前沿，又分布得比较开。

一代中最重要的三件事是：

1. **把父代和子代合起来比**：$R_t=P_t\cup Q_t$，共 $2N$ 个候选。
2. **按占优关系分层**：先考虑 $F_1$，再考虑 $F_2$，依次往后。
3. **某一层放不下时**：只在这一层按拥挤距离从大到小截取，直到凑满 $N$ 个。

可以先记住：**层号小的优先；层号相同时，周围更空的优先。** 后面所有符号都是在实现这句话。

### 和课件一致的符号表

| 符号 / 名称 | 在课件中的含义 | 容易混淆的地方 |
| --- | --- | --- |
| $N$ | 父代、子代各自的种群规模 | 合并后是 $2N$，下一代仍是 $N$ |
| $M$ | 目标函数的个数 | 本文例子 $M=2$ |
| $P_t$、$Q_t$ | 第 $t$ 代父代种群、子代种群 | 不是两个目标函数 |
| $R_t$ | 合并种群 $P_t\cup Q_t$ | 相同目标值的不同个体仍分别计数 |
| $\mathcal F=(F_1,F_2,\ldots)$ | 非劣层的有序集合 | 图中花体 $\mathcal F_i$ 与正文 $F_i$ 指同一层 |
| $p,q$ | 参与比较的两个个体 | $p\prec q$ 表示 $p$ 支配 $q$ |
| $n_p$ | 支配 $p$ 的个体数 | 是“别人压过我”的数量 |
| $S_p$ | 被 $p$ 支配的个体集合 | 是“我压过谁”的名单 |
| $p_{\mathrm{rank}}$ / $\operatorname{rank}(p)$ | 个体 $p$ 的非劣层号 | $F_1$ 的 rank 为 1 |
| $I$、$l=|I|$ | 正在计算拥挤距离的某一层、该层人数 | 不把所有层混起来算距离 |

| $d_i$ / $I[i]_{\mathrm{distance}}$ | 个体 $i$ 的拥挤距离 | 值越大，优先级越高 |
| $\prec_n$ | 拥挤比较算子 | 先比较 rank，再比较 distance |

课件的 `fast-non-dominated-sort(P)` 中，$P$ 是函数接收到的任意种群；外层算法把 $R_t$ 传给它，所以这里的 $P$ 不一定是父代 $P_t$。同理，排序伪代码里的临时集合 $Q$ 用来存“下一层”，不要把它和子代 $Q_t$ 混为一谈。

## 占优关系：什么叫支配，什么叫互不支配

设个体 $p$ 的目标向量为 $(f_1(p),\ldots,f_M(p))$。所有目标都越小越好时：

$$
p\prec q
\iff
\left[\forall m,\ f_m(p)\le f_m(q)\right]
\ \text{且}\ 
\left[\exists m,\ f_m(p)<f_m(q)\right].
$$

读成中文就是：**每一项都不差，而且至少一项更好。**

- A = $(1,5)$，F = $(4,5)$：A 在 $f_1$ 上更小、$f_2$ 相等，所以 A 支配 F。
- A = $(1,5)$，B = $(3,3)$：A 的 $f_1$ 更好，B 的 $f_2$ 更好，二者互不支配。
- 两个不同个体的目标向量完全相同：没有“严格更好”的一项，也互不支配。

在目标平面上，支配一个点的个体位于它的左下方（允许在一条边上，不能两项都相等）。注意图里画的是**目标值**，不是原始决策变量。两种设计方案可能目标值接近，决策变量却差得很远。

先点“看相等的一项”，核对 A 为什么能支配 F；再点“看互不支配”，感受为什么不能只按 $f_1$ 排序。这里的图与数值表始终使用同一组数据。

如果某个目标要最大化，可以先取负号转成最小化；不要一边用“越大越好”的目标，一边直接套上面的不等号。带约束问题还需要明确可行性和约束违反量的比较规则，本文暂不引入。

## 非劣排序：一层一层剥下去

### 非劣层和真正的 Pareto 前沿

**$F_1$ 是当前候选集合中，没有被任何其他候选支配的个体。** 取走 $F_1$ 后，再从剩余集合找没有被支配的个体，得到 $F_2$；继续得到 $F_3$。

因此，“属于 $F_2$”表示：它在完整候选集合里被支配，但删除第一层后就不再被剩余个体支配。并不表示“恰好被两个人支配”。层号也不是支配计数。

还要区分两个“前沿”：$F_1$ 只对**当前种群**非劣；真实 Pareto 前沿要求在**整个可行域**里不存在支配它的解。遗传算法找到的 $F_1$ 可能仍离真实前沿很远。

### 全文贯穿的 12 个个体

令 $N=6$，父代和子代各有 6 个，目标均最小化：

| 个体 | $(f_1,f_2)$ | 来源 | 在 $R_t$ 中的非劣层 |
| --- | --- | --- | --- |
| A | $(1,5)$ | $P_t$ | $F_1$ |
| B | $(3,3)$ | $Q_t$ | $F_1$ |
| C | $(5,1)$ | $Q_t$ | $F_1$ |
| D | $(2,8)$ | $P_t$ | $F_2$ |
| E | $(3,6)$ | $Q_t$ | $F_2$ |
| F | $(4,5)$ | $P_t$ | $F_2$ |
| G | $(6,4)$ | $Q_t$ | $F_2$ |
| H | $(8,2)$ | $P_t$ | $F_2$ |
| I | $(4,8)$ | $Q_t$ | $F_3$ |
| J | $(6,6)$ | $P_t$ | $F_3$ |
| K | $(7,5)$ | $Q_t$ | $F_3$ |
| L | $(9,4)$ | $P_t$ | $F_3$ |

这里字母 F、I 是个体编号；非劣层 $F_i$ 和拥挤距离函数的输入集合 $I$ 另有含义，要结合上下文看。

按最直观的办法逐层筛选，会得到：

$$
F_1=\{A,B,C\},\qquad
F_2=\{D,E,F,G,H\},\qquad
F_3=\{I,J,K,L\}.
$$

同层两点必定互不支配。但**第一层的每一个点，不必支配第二层的每一个点**。例如 C = $(5,1)$ 和 D = $(2,8)$ 就互不支配；D 是因为被 A 支配而没进第一层。

直观算法每找一层，都重新比较剩余的个体。若每层很薄，就会反复做很多相同的比较。课件下一页的“快速”主要解决这件事。

## 快速非劣排序：记录 n_p 和 S_p，就不用反复比较

### 第一步：两两比较，存下结果

对每个 $p$，初始化 $n_p=0$、$S_p=\varnothing$，再与每个 $q$ 比较：

- 若 $p\prec q$，把 $q$ 加进 $S_p$。
- 若 $q\prec p$，让 $n_p$ 加 1。
- 若互不支配，两者都不更新。

比较结束，所有 $n_p=0$ 的个体直接进入 $F_1$，令 $p_{\mathrm{rank}}=1$。

例如，E = $(3,6)$ 被 A、B 支配，因此 $n_E=2$。D = $(2,8)$ 只被 A 支配，因此 $n_D=1$。**两者都在第二层，计数却不同。**

### 第二步：处理一层，给它支配的人减计数

已知 $F_i$ 后，遍历其中每个 $p$，再遍历 $S_p$ 中的每个 $q$，执行：

$$
n_q\leftarrow n_q-1.
$$

为什么减 1？因为这个支配 $q$ 的 $p$ 已经被放进当前层，下一轮只关心剩余个体之间的关系。当 $n_q$ **刚变成 0**，说明剩余集合里再也没有人支配它，于是把它放入临时集合 $Q$，设 $q_{\mathrm{rank}}=i+1$。处理完整个 $F_i$ 后，再令 $F_{i+1}=Q$。

不要把一个计数刚归零的点马上当成本层成员继续展开；它属于**下一层**，应该等本层全部处理完再处理。

::nsga-explorer{mode="sorting"}
::

点击“处理这一层”，同时看散点图和计数表。初始 $n_p=0$ 的 A、B、C 是第一层；处理它们后 D—H 全部归零，但 I—L 还没有归零。

一个具体追踪：J = $(6,6)$ 最初被 A、B、C、E、F、G 支配，故 $n_J=6$。处理 $F_1$ 后减去 A、B、C，剩 3；处理 $F_2$ 后再减去 E、F、G，变 0，所以 J 进入 $F_3$。

### 对照课件的伪代码

下面保留课件的函数名和变量名，补上显式初始化。这里使用 1 起始的层号。

```text
fast-non-dominated-sort(P)
    F_1 = ∅
    for each p ∈ P
        S_p = ∅
        n_p = 0
        for each q ∈ P
            if p ≺ q
                S_p = S_p ∪ {q}
            else if q ≺ p
                n_p = n_p + 1
        if n_p == 0
            p_rank = 1
            F_1 = F_1 ∪ {p}

    i = 1
    while F_i ≠ ∅
        Q = ∅
        for each p ∈ F_i
            for each q ∈ S_p
                n_q = n_q − 1
                if n_q == 0
                    q_rank = i + 1
                    Q = Q ∪ {q}
        i = i + 1
        F_i = Q
    return 所有非空的 F_i
```

第一轮的 $n_p$ 是“原集合中有多少人支配我”；递减以后，含义变成“尚未处理的支配者还有多少”。最终计数都归零，但每个个体的 rank 已经保存，不会都变成第一层。

设输入大小为 $K=|P|$，两两比较的时间复杂度为 $O(MK^2)$，保存所有 $S_p$ 最坏需要 $O(K^2)$ 空间。外层传入 $K=2N$，所以仍记为 $O(MN^2)$。这比朴素逐层重新比较的最坏 $O(MK^3)$ 好；“快速”不意味着没有两重循环。

## 拥挤距离：同一层里，优先保留周围更空的点

### 为什么分层以后还不够

本例 $F_1$ 有 3 个，全部保留后只剩 3 个位置；$F_2$ 有 5 个，装不下了。可这 5 个互不支配，rank 也一样，用什么决定留谁？

如果只按 $f_1$ 从小到大留前三个，会把结果挤向一个方向。NSGA-II 用**拥挤距离**估计个体在目标空间中的局部稀疏程度，倾向保留周围更空的个体，让取舍范围更丰富。

课件里的“距离”不是到原点的距离，也不是两个点之间的欧氏距离，更不是点到真实 Pareto 前沿的距离。它是**每个目标轴上，两侧邻居的归一化间隔之和**。

### crowding-distance-assignment(I) 的每一步

给定同一非劣层 $I$，令 $l=|I|$：

1. 先把每个个体的 distance 设为 0。
2. 对每个目标 $m$，把 $I$ 按该目标值从小到大排序。
3. 把这个排序的首、尾个体的 distance 设为 $\infty$，优先保护边界。
4. 对内部位置 $i=2,\ldots,l-1$，累加下面的间隔。

$$
I[i]_{\mathrm{distance}}
\leftarrow
I[i]_{\mathrm{distance}}+
\frac{I[i+1]_m-I[i-1]_m}{f_m^{\max}-f_m^{\min}}.
$$

这里 $f_m^{\max}$ 和 $f_m^{\min}$ 取自当前层 $I$。分子是**前后两个邻居之间的间隔**，没有用当前点自己的坐标做差。分母消除单位与尺度影响；否则“秒”换成“毫秒”就可能改变选择结果。

每个目标都要重新排序。第 $m$ 个目标下的 $i-1,i+1$，不一定与另一个目标下是同一对个体。在本例二维严格下降的一层里，邻居集合恰好相同、顺序相反；高维或含相同坐标时不能据此偷懒。

```text
crowding-distance-assignment(I)
    l = |I|
    for each individual in I
        individual_distance = 0
    if l ≤ 2
        将所有个体的 distance 设为 ∞；return
    for each objective m
        I = sort(I, m)                   // 按目标 m 升序
        if f_m^max == f_m^min
            continue                    // 零极差没有间隔信息，避免除零
        I[1]_distance = I[l]_distance = ∞
        for i = 2 to l − 1
            I[i]_distance +=
                (I[i+1]_m − I[i−1]_m) / (f_m^max − f_m^min)
```

零极差的处理是这里显式补充的实现约定：跳过该目标，不凭这一条常数轴任意挑两个“边界”。图片中的简写没有展开这个情况。相同目标值会带来排序并列；本演示用个体字母顺序稳定处理并列，实际算法也可以使用事先规定的随机规则。

### 手算 F₂：两个边界加一个内部点

当前 $I=F_2=\{D,E,F,G,H\}$。按 $f_1$ 升序是 D、E、F、G、H；按 $f_2$ 升序是 H、G、F、E、D。两轴的极差都是 $8-2=6$。

| 个体 | $f_1$ 的贡献 | $f_2$ 的贡献 | 总拥挤距离 |
| --- | --- | --- | --- |
| D | 边界 | 边界 | $\infty$ |
| E | $(4-2)/6=2/6$ | $(8-5)/6=3/6$ | $5/6$ |
| F | $(6-3)/6=3/6$ | $(6-4)/6=2/6$ | $5/6$ |
| G | $(8-4)/6=4/6$ | $(5-2)/6=3/6$ | $7/6$ |
| H | 边界 | 边界 | $\infty$ |

所以这一层只选 3 个时，先选 D、H，再选 G。E 和 F 距离相同，但本次都落选，不需要打破它们的并列。

::nsga-explorer{mode="crowding"}
::

依次试三件事：选 G 查看两项分数；选 D 观察边界为什么是 $\infty$；勾选“$f_2$ 单位放大 1000 倍”，确认距离没有改变。然后移动 F：F 的邻居仍是 E 和 G，所以它自己的距离不变，而 E、G 的间隔会改变。这能帮助你真正记住分子为何是 $I[i+1]_m-I[i-1]_m$。

这里的 $\infty$ 是优先级标记，不是无限大的实际几何距离。它也不意味着“任何时候必定保留”：较差层的边界不能越过更好层；同层若有多个 $\infty$ 而剩余位置不足，仍需打破并列。课件“边界点总被选择”的注释应在这个容量条件下理解。

## NSGA-II：把各部分拼成一代

### 精英策略，发生在父代和子代的联合筛选

如果只在 $Q_t$ 里选择，新子代即使整体变差，也可能丢掉父代里的好解。NSGA-II 合并 $P_t$ 和 $Q_t$ 后统一比较，让优秀父代也有机会存活。这就是这里的精英保留。

“精英”并不是所有非劣解永远不丢：当 $|F_1|>N$ 时，第一层内部也要按拥挤距离删减。算法只有有限的 $N$ 个名额。

### 对照照片里的整体流程

```text
R_t = P_t ∪ Q_t
𝓕 = fast-non-dominated-sort(R_t)
P_(t+1) = ∅ and i = 1

while F_i 存在 and |P_(t+1)| + |F_i| ≤ N
    crowding-distance-assignment(F_i)
    P_(t+1) = P_(t+1) ∪ F_i
    i = i + 1

if |P_(t+1)| < N
    crowding-distance-assignment(F_i)
    Sort(F_i, ≺_n)                       // 本层 distance 从大到小
    P_(t+1) = P_(t+1) ∪ F_i[1 : (N − |P_(t+1)|)]

Q_(t+1) = make-new-pop(P_(t+1))
t = t + 1
```

照片里印着 `until |P_(t+1)| + |F_i| ≤ N`。结合后面的“整层加入”操作，执行意图应读成：**只要这一层还装得下，就继续加入**。因此上面明确写成 `while ... ≤ N`；若真使用“重复直到”的 until 语义，停止条件应是“下一层装不下”，不能照字面机械翻译。

还有两个实现细节：进入截断层排序之前，必须先计算**该截断层**的拥挤距离；如果前面恰好装满 $N$ 个，则跳过截断操作，避免再访问不存在或无需处理的下一层。

每一行可以这样读：

| 课件语句 | 实际在问什么 |
| --- | --- |
| $R_t=P_t\cup Q_t$ | 旧解和新解，谁更值得保留？ |
| `fast-non-dominated-sort(R_t)` | 把候选分成第一梯队、第二梯队…… |
| $|P_{t+1}|+|F_i|\le N$ | 这一整层还装得下吗？ |
| $P_{t+1}=P_{t+1}\cup F_i$ | 装得下就整层保留，不在层内删人 |
| `Sort(F_i, ≺_n)` | 装不下的这一层，谁周围更空？ |
| $F_i[1:(N-|P_{t+1}|)]$ | 按排好序的列表，取剩余名额那么多人 |
| `make-new-pop(P_(t+1))` | 用新父代选择配偶、交叉、变异、评价，得到新子代 |

其中切片采用课件的 **1 起始、包含末端**记法；实现成 Python 或 JavaScript 时，需要换成对应语言的 0 起始切片，别多取或少取一个。

$$
P_{t+1}=\{A,B,C,D,H,G\},\qquad |P_{t+1}|=6.
$$

这里保留了父代的 A、D、H，也保留了子代的 B、C、G。**来自父代还是子代不是优先级条件。** E、F 因第二层的距离排序落选，I、J、K、L 因属于第三层落选。即使第三层有人距离为 $\infty$，也不能跳过第二层抢位置。

### 拥挤比较算子 ≺_n

课件中的 $\prec_n$ 把两条比较规则写在一起：

$$
p\prec_n q
\iff
\bigl(p_{\mathrm{rank}}<q_{\mathrm{rank}}\bigr)
\ \text{或}\ 
\bigl(p_{\mathrm{rank}}=q_{\mathrm{rank}}
\ \text{且}\ p_{\mathrm{distance}}>q_{\mathrm{distance}}\bigr).
$$

注意两个方向：**rank 越小越好，distance 越大越好。** 若二者都相等，规则没有偏好，通常随机打破并列；本交互为了重置后结果可复现，用字母顺序作为并列规则。

在截断层里大家的 rank 一样，所以 $\prec_n$ 退化成按 distance 降序。它也常用于二元锦标赛：随机抽两个候选，用这个规则选胜者。锦标赛可能重复选中同一父代，因为它是在选择繁殖机会。

### make-new-pop：它不是再筛一次幸存者

环境选择决定“谁存活到下一代”；繁殖选择决定“谁获得交叉、变异的机会”。二者作用不同。

`make-new-pop(P_(t+1))` 通常包含：

1. 用二元锦标赛选交配个体，比较依据是 rank 和拥挤距离。
2. 交叉组合父代的决策变量，再以变异产生扰动。
3. 对新个体计算全部 $M$ 个目标值，凑齐 $N$ 个子代，得到 $Q_{t+1}$。

不能直接对散点图坐标随便“交叉”并假装得到有效方案：真正的遗传操作通常发生在**编码或决策变量**上，之后才通过目标函数映射到图里的点。二进制编码、实数编码会选用不同的交叉与变异算子；NSGA-II 的分层和保留规则并不强制某一种编码。

从头启动算法时，先随机初始化并评价 $P_0$，对它分层并计算距离，再通过繁殖得到 $Q_0$，这样才能进入图中的 $R_0=P_0\cup Q_0$。之后循环上面的流程，直到达到代数或评价预算等停止条件。通常报告最终种群中的非劣解集，供决策者选择；有限次迭代并不保证已找到真实 Pareto 前沿。

本页交互演示的是**固定候选集合上的排序、距离计算与环境选择**。它没有模拟随机交叉和变异；后两步需要具体的决策变量、目标函数和遗传算子才能运行。

## 自测：能回答这六题，就抓住了关键

先遮住下面的答案，试着口头解释，不必背长段代码。

1. 最小化问题中，$p=(2,3)$、$q=(2,5)$，谁支配谁？若二者都为 $(2,3)$ 呢？
2. 一个点 $n_p=5$，能否断定它属于 $F_5$？
3. 如果两个点 rank 分别为 1 和 2，距离分别为 0.1 和 $\infty$，优先谁？
4. 为什么拥挤距离的分子是两侧邻居之差，而不是到原点的距离？把一个目标单位放大 1000 倍会怎样？
5. 本例若 $N=3$，用同一批 12 个候选做环境选择，会选谁？若 $N=2$ 呢？这里仅改变保留容量，不把候选人数再解释成 $2N$。
6. 为什么 NSGA-II 要比较 $P_t\cup Q_t$，而不是只比较 $Q_t$？

### 自测答案

1. $p\prec q$：第一项相等，第二项更小。若两项都相等，二者互不支配。
2. 不能。$n_p$ 是支配者计数；rank 是逐层删除后找到它的层号。例如本例 E 的 $n_E=2$、D 的 $n_D=1$，却同属 $F_2$。
3. rank 为 1 的点。拥挤距离只在 rank 相同时参与优先级比较。
4. 要估计周围的稀疏程度，才看邻居的间隔。归一化以后，单位的正比例变换同时作用于分子和分母，结果不变；非线性变换则不保证保持距离排序。
5. 容量为 3 时恰好保留 $\{A,B,C\}$，不用截断下一层。容量为 2 时截断的是 $F_1$，A、C 是边界，保留 $\{A,C\}$。这也说明第一层不一定全部存活。
6. 让优秀父代也参与竞争，避免它们仅因子代替换而丢失，是精英策略的体现。
