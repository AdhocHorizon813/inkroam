## 生效与保存

优先级：现代幻境及浏览器支持 → 漫光玻璃总开关 → 当前组件材质必须为 liquid → 全局覆盖开启时使用全局参数，否则使用分项参数 → 液态玻璃开关。

全局覆盖默认关闭；开启时不删除分项数据，关闭后恢复分项。全局液态玻璃关闭时销毁所有符合条件的折射层；不会修改原液态玻璃、云母、亚克力配方。全局开启也不能将云母/亚克力替换为漫光玻璃。

配置保存在既有 `paper-trail-appearance-v5` 的 `glassComponents` 与 `glassGlobal`。旧全局通透度、抗锯齿迁移到各分项；新增设置不随“默认设置”的明暗预设重置，整体“恢复默认”则重置。开启默认设置仍会切换材质，因此可能间接使玻璃渲染器退出，这是材质门控的预期行为。

| 组件 | 材质来源 |
| --- | --- |
| 导航栏、阅读面板、确认窗、图片查看按钮 | 导航材质 |
| 正文与首页卡片、PDF 工具栏 | 内容材质 |
| 音乐面板 | 音乐材质 |
| 正文工具、正文工具轨道、下拉菜单与日历 | 下拉材质 |
| 音乐/显示入口 | 分别为音乐/导航材质 |
| 指示器、滑条玻璃滑块 | 原始控件所在组件的材质，不能从移出滚动区的光学层判断 |

## 质量与性能参数

| 参数 | 档位/范围 | 作用与代价 |
| --- | --- | --- |
| 液态玻璃 | 关/开 | 关闭释放该组滤镜，恢复原材质 |
| 通透度 | 0–100% | 磨砂扩散量，非白色遮罩透明度 |
| 抗锯齿 | 关/开 | 光学边缘 coverage 过渡 |
| 抗锯齿采样倍数 | 1 / 1.5 / 2 | 乘在每条边上；2× 最多四倍贴图像素，不是浏览器 MSAA |
| 折射贴图精度 | 自动 / .25 / .5 / .75 / 1 / 1.5 / 2 | 自动取 DPR、上限 2；只控制位移贴图，并非背景采样分辨率 |
| 单层贴图预算 | 50 / 150 / 300 万像素 | 包含 AA，超限会降低实际倍率；不是全站显存上限 |
| 贴图边长上限 | 1024 / 2048 / 4096 | 同时限制最长边，防止狭长贴图仅靠面积预算失控 |
| 滤镜更新频率 | 不限 / 15 / 30 / 60 Hz | 限制本引擎参数 flush，非页面 FPS，也不能限制浏览器随背景变化进行的合成 |
| 尺寸稳定后更新贴图 | 实时 / 80 / 160 ms | 形状持续变化时复用已解码贴图，稳定后重建；首张立即生成，临时拉伸可能改变运动中的观感 |
| 控件弹性形变 | 关/开 | 只影响指示器/滑块，关闭按压和速度拉伸，仍保留移动、拖拽、选择和目标尺寸变化 |

最终采样倍率取：请求精度×AA、面积预算对应倍率、边长上限对应倍率三者最小值。正文预算包含上下 bleed。未更改配置时，新追加性能项使用不限制刷新/实时更新/保留形变，避免偷偷改变既有设计。

## 历史：已替换的设备推荐

点击始终可用的“应用设备推荐设置”，弹出原生 dialog 确认；复用默认设置确认窗的材质、开合动画、按钮和符号。取消/Esc 不应用；确认后不显示“已应用”常驻提示。弹窗明确显示估算档位及覆盖范围。

只读取本机可用的 `hardwareConcurrency`、`deviceMemory`、视口实际像素量与减少动态效果偏好；不上传、不开 GPU 基准测试、不猜测独显型号。信息缺失按均衡档处理。低核心/低内存/高像素量或减少动态效果使用节能档；满足明确条件才使用精细档。

分项推荐在节能档关闭正文、指示器、滑块折射，其余降低精度、频率并延后贴图更新。全局覆盖开启时推荐统一参数，不修改保留的分项，不进行按组件关闭。保留个人通透度，不自动开启总开关，也不修改材质、壁纸。推荐仅为启发式起点，不保证实际流畅。
