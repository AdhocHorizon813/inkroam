# 文章图片灯箱

文章正文里的图片点击后会进入全屏灯箱，支持缩放、平移与完整的键盘操作。本文记录它的行为、设计取舍与实现位置，方便后续维护和二次开发。

## 用户可见的功能

| 操作 | 行为 |
| --- | --- |
| 点击正文图片 | 打开灯箱（任何 `<img>` 都生效） |
| 双击图片 | 在光标处放大到 250%；再次双击复位回适应视图 |
| 滚轮 / 触控板 | 以光标为锚点连续缩放，范围 100%–600% |
| 拖拽（放大后） | 平移画面，边界约束保证至少 64px 留在视口内 |
| 双指捏合（触屏） | 以两指中点为锚点缩放 |
| `+` / `=` | 以视口中心放大 25% |
| `-` / `_` | 以视口中心缩小 25% |
| `0` | 复位到适应视图 |
| `←` / `→` | 上一张 / 下一张（切换后自动复位缩放） |
| `Esc` | 关闭灯箱 |
| 单击图片 | 关闭灯箱（仅在未缩放、未拖拽时；延迟 240ms 以区分双击） |
| 点击遮罩 / × | 关闭灯箱 |

左上角显示 `当前序号 / 总数`：放大时显示百分比，未放大时显示「双击或滚轮缩放」提示（移动端隐藏）。放大时图注会淡出，避免压在被放大的图片上。

## 设计取舍与原因

### 1. 事件委托，而不是覆盖 MDC 组件

`@nuxtjs/mdc` 把 Markdown 图片渲染成裸 `<img>`（没有包裹层，也没有尺寸属性），没有稳定的组件入口可以挂钩点击。于是改为在文章容器 `.article-content` 上委托 `click` / `keydown`：

- 覆盖未来新增的图片和手写 HTML `<img>`；
- 不侵入内容渲染管线。

实现见 `app/pages/posts/[slug].vue` 的 `collectImages` / `openLightbox` / `onContentClick` / `onContentKeydown`。

### 2. Teleport 到 `<body>`

现代主题下 `.article-page` 使用了 `backdrop-filter`，它会创建包含块，使 `position: fixed` 被「困」在文章区域内。因此灯箱用 `<Teleport to="body">` 挂到 `body` 下，脱离任何祖先的包含块。

### 3. 单击关闭与双击缩放如何共存

两者都从 `click` 触发，直接并存会互相打架。方案是：

- 单击后延迟 `CLOSE_DELAY = 240ms` 再关闭；
- 双击会取消这个定时器并执行缩放；
- 一次拖拽位移超过 3px 时，这次点击不触发关闭；
- 已放大时单击图片不关闭（此时点击语义让给平移），关闭请用遮罩、× 或 `Esc`。

### 4. 缩放锚点的数学

所有缩放都保证「光标下的那个像素不动」。做法是取图片未变换的布局盒（`offsetLeft` / `offsetTop` / `offsetWidth` / `offsetHeight` 不受 `transform` 影响），据此推导屏幕坐标到图片局部坐标的映射：

```
t' = (q - c) - (s'/s) * (q - c - t)
```

其中 `c` 是未变换的中心，`t` 是当前平移量，`q` 是光标屏幕坐标，`s` / `s'` 是缩放前后倍率。捏合手势则把「按下时的两指中点」映射到「当前两指中点」，避免逐帧累积漂移。

### 5. 入场动画与缩放共用 `transform` 的冲突

缩放通过 `<img>` 的内联 `transform` 实现；如果入场动画也写在 `.image-lightbox__image` 上，两者会互相覆盖。因此把入场/退场缩放动画移到 `.image-lightbox__figure`，让 `<img>` 独占自己的 transform。

### 6. 滚动锁与滚动条补偿

打开时给 `<html>` 设 `overflow: hidden`，并把滚动条消失产生的宽度差补到 `padding-right`，关闭时还原，避免页面横向跳动。关闭后还会把焦点还给打开前的元素。

### 7. 无障碍

- 正文图片在挂载时补上 `tabindex="0"`、`role="button"`、`aria-label="放大图片：<alt>"`，键盘可聚焦并回车/空格打开；
- 灯箱为 `role="dialog"` + `aria-modal="true"`，打开时聚焦关闭按钮，`Tab` 在按钮间循环（焦点陷阱）；
- 缩放百分比使用 `tabular-nums`，数字变化时不抖动；
- `prefers-reduced-motion: reduce` 下关闭全部过渡动画。

## 参数速查

| 常量 | 值 | 说明 |
| --- | --- | --- |
| `MIN_SCALE` | 1 | 适应视图，不会比初始更小 |
| `MAX_SCALE` | 6 | 放大上限 |
| `DOUBLE_CLICK_SCALE` | 2.5 | 双击目标倍率 |
| `WHEEL_SENSITIVITY` | 0.0022 | 滚轮指数系数，`factor = exp(-deltaY * unit * k)` |
| `PAN_MARGIN` | 64 | 平移时至少保留在视口内的像素 |
| `CLOSE_DELAY` | 240 | 单击关闭的延迟，用于让位双击 |

滚轮做了 `deltaMode` 归一化：行模式按 16px/行、页模式按视口高度折算，保证不同浏览器与设备手感一致。

| `app/assets/css/main.css` | `.image-lightbox*` 样式、光标状态、入场动画、reduced-motion |

顺带记录一处相关修复：Markdown 图片是裸 `<img>`，没有宽高属性，`.article-content img` 必须显式声明 `display: block; max-width: 100%; height: auto;`，否则在部分主题下会被拉伸变形。

## 验证方式

```bash
npm run typecheck
npm run generate
npm run dev   # 然后手动过一遍下面的清单
```

手动清单：

1. 点击正文图片 → 灯箱打开，左上角显示 `1 / N`；
2. 双击 → 放大到 250%，百分比出现，图注淡出；
3. 滚轮上下 → 以光标为中心缩放；
4. 放大后拖拽 → 画面跟随，松手后不会飞出视口；
5. 再双击 → 复位，图注恢复；
6. 单击 → 约 0.24s 后关闭，页面滚动恢复且无横向跳动；
7. `←` / `→` 切图后缩放复位；`Esc` 关闭；
8. 键盘 `Tab` 到正文图片，回车打开。

## 已知取舍

- 放大可以超过图片的自然尺寸（上限 600%），这是刻意保留的：用户可能想看清细节，像素化程度取决于原图分辨率。
- `Esc` 始终直接关闭，不复位缩放，更符合「退出」的直觉。
- 触屏上隐藏提示文案，避免小屏拥挤；捏合手势本身足够可发现。
- 单击关闭的 240ms 延迟是刻意的：它换来双击缩放的可用性，正常点击几乎感知不到。
