# 漫光玻璃 · 开发收尾

2026-11-01，用户确认本轮液态玻璃开发完成。产品名称定为「漫光玻璃」，取自「纸上漫游」以及光线穿过玻璃时的折射与流动。代码基线 `9645e3b`，开始收尾时工作区干净。

## 发布范围与名称

阅读外观 → **漫光玻璃设置**，总开关默认关闭。主菜单入口、二级标题、总开关、分项开关及恢复默认确认文案统一命名。原材质菜单的「液态玻璃」仍是材质名称，与亚克力、云母并列，不改它们的配方。

共有 13 组：导航栏、正文与首页卡片、阅读面板、音乐面板、正文工具、正文工具轨道、下拉与日历、确认弹窗、PDF 工具栏、图片按钮、底部入口、滑动指示器、滑条玻璃滑块。全局覆盖与分项参数并存；恢复默认按当前全局模式应用相应范围，保留另一套数据。

既有 `paper-trail-appearance-v5`、`experimentalLiquidGlass`、指令和内部文件标识保持兼容。产品改名不清空用户偏好、不自动开启功能。新增 `tools-track` 在旧数据缺失时继承原 `tools`，随后独立保存。

## 当前实现与维护边界

- 模块按需加载，Chromium 背景滤镜路径；纸媒、不支持的浏览器和减少透明度偏好保留原材质。不能将本轮完成理解为跨浏览器实现已经一致。
- 控件实体与交互保持原位，透明投影负责跨宿主采样。不要再次复制滑条白色静止盖，或把 `inert` 等同于“已经不可见”。
- `opening/open/closing/closed` 由动画所有者维护。退出时保留光学效果，完成后休眠已解码资源；重开复用。卸载或关闭功能时清理控制器、观察器、弹簧及任务。
- 正文使用视口区域光学层，避免整篇文章生成巨大贴图。参数约束的是每层位移贴图，不是整个页面的 GPU 显存或帧率保证。
- 分段轨道与指示器各有光学职责；导航没有附加轨道，正文工具轨道复用自身表面。指示器按压形变、折射深度随尺寸变化，不能回退为统一固定深度。
- 引擎保留 gentpan MIT 与 Kyant Apache-2.0 署名，见 [第三方声明](../THIRD_PARTY_NOTICES.md)。这不是物理焦散模拟，也不宣称与 Apple 或 Android 原生渲染逐像素一致。

本轮保留 CSS 配方、布局、动效参数及默认光学值；追加修正了用户反馈的阴影出现时机。后续按实际 bug 小范围维护；不要因历史断点写着“尚未实现”而重做已经合并的功能。

## 收尾中追加的菜单阴影修复

用户反馈面板进入和一、二级菜单切换时，轨道阴影先缺失、后出现。修复两条独立路径：

1. 轨道染色与阴影不再等待 SVG 贴图解码；初始几何对齐后即显示，滤镜仍按实际解码状态启用。关闭与销毁保留原生命周期，不提前冒充光学就绪。
2. 子页运动中的外置轨道原先使用零下限的 `inset(... round ...)`，即使完全位于视口内，也把外阴影裁到自身边框。改为相对真实视口/展开区的裁切（允许负 inset），使可见阴影在移动和静止时连续。保留宿主 CSS 圆角，不改变阴影参数。

回归覆盖解码前展示、销毁恢复、原生锚点进入和非锚点退出裁切。未做浏览器像素验收，最终视觉仍由用户确认；不能把第一条修复的通过记录当成第二条已经实机解决的证明。

## 菜单标题与返回按钮

用户追加要求平滑一、二级菜单的头部切换。返回圆盘保持原尺寸与样式，补上淡入淡出、轻微缩放和转动；DISPLAY 与返回按钮交替时，所在区域的高度以 260ms 非线性曲线过渡，标题与下方内容不再瞬间跳位。标题按方向短距离平移并交叉淡化，退出标题不占额外布局。隐藏返回按钮立即禁用交互，标题保留明确的可访问名称；减少动态效果偏好下关闭这些过渡。

面板本身的展开动画、子页切换曲线、光学参数及关闭按钮未改。此项有源码与类型检查，尚未进行真实浏览器动画验收。

用户随后发现长标题在交叉切换中短暂换行：退出文字绝对定位时受新标题较短的宽度限制。标题文字补 `white-space: nowrap`，保持原字号和动画；不截断「设置」二字。
