# 浏览器回归验收：保护现有设计

状态：待执行。建立于 2026-09-27；这是验收协议，不是测试通过记录，也不是重新设计方案。

## 固定条件

- 用同一 commit、浏览器版本、缩放比例、背景图、外观设置、窗口尺寸对比；记录这些信息，不能把不同背景的色差当作回归。
- 现代浅色、现代深色、纸媒浅色、纸媒深色分别检查；覆盖桌面细指针/hover 与窄屏触摸。仅缩小窗口不等于切换到触摸滚动分支，记录媒体查询实际结果。
- 建议固定 1440×900 与 390×844 CSS 像素；另测桌面窄窗口，验证输入能力和视口宽度不是同一条件。
- 保留现有材质、尺寸、字体、颜色、布局、动画时长和曲线。发现问题先记录，不借验收调整设计。
- 临时截图/录屏放在被忽略的工作目录，不把私有内容、localStorage 全量导出或调试日志提交入库。

## 四条高风险路径

| 路径 | 操作 | 验收点 | 留存证据 |
| --- | --- | --- | --- |
| 导航与滚动 | 长文章滚至中部→短页→后退；刷新；目录与正文标题跳转 | 顶栏按既有规则常驻；回退恢复位置；锚点不被遮挡；没有重复整页入场；滑条显隐不使内容横移 | 顶栏/正文矩形、滚动容器与 scrollTop；同视口截图、切换录屏 |
| 日期焦点 | 打开高级搜索，Tab 进入日期输入和日历按钮，手输完整/半截/无效/越界日期 | 只有约定的外层圆角焦点框；无双框；无效日期恢复、越界提示；半截输入不清空已有筛选；URL 与有效值一致 | 聚焦前后截图、activeElement、外层与输入计算样式、URL |
| 浮层开合 | 打开标签，输入筛选词；页底打开日历；滚动/resize；Esc/外部点击收起 | 不溢出视口；翻转后从对应边收回；退场未被后排字段遮住；材质在退场中保留；焦点行为合理 | data-flip、触发框与浮层矩形、开合录屏、键盘焦点 |
| 默认设置确认 | 启用/禁用分别取消、Esc、确认；快速操作；随后切换浅/深/自动 | 取消/Esc 不改设置；退场文案不闪变；按钮响应和原动效保留；启用时受管值跟随明暗，禁用时手动值保留 | 操作前后受管字段摘要、标题退场录屏、最终主题属性 |

补充：开启系统“减少动态效果”后复测开合及锚点，不应依赖动画完成才能使用；确认弹窗的初始焦点仍在取消按钮。触摸设备需真机补测滚动与点击，桌面模拟不代表真机通过。

## 记录与结论

每次记录：commit、环境、模式、视口、输入能力、操作、预期、实际、证据路径、通过/失败/未验证。不支持的浏览器能力记录降级行为，不改成伪造的通过。

`npm run check -- --built` 覆盖逻辑/源码契约/静态产物；真实 Vue 测试覆盖部分响应式调度。两者都不证明像素、模糊取样、原生焦点或逐帧动画正确。浏览器不可连接时，这份清单继续保持“待执行”。
