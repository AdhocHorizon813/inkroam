## 页内查找

仅遍历当前正文已渲染、可见的文字，支持普通文字和代码；大小写不敏感，按完整输入的字面字符串匹配，不沿用全站多词AND。连续高亮span中的词可以跨节点命中，不跨段落。排除控件、隐藏内容与KaTeX重复的MathML。

CSS Custom Highlight API绘制全部命中与当前命中，不插mark、不替换Vue管理的文本。支持上一处/下一处、Enter/Shift+Enter、Esc收起，遵循减少动态效果设置。保持浏览器Ctrl/Cmd+F原有行为。PDF附件使用阅读器自己的独立文内查找；未渲染图表、图片文字不做OCR。

当前依赖现代浏览器的CSS Highlights：不支持时仍可查找和跳转，但没有彩色高亮。可见数学公式的字符排列不等同于TeX输入，不承诺用LaTeX源码检索公式。

## 导出

整篇正文或按H2选择一个小节，支持PDF/PNG。分块方式为逐节选择保存，不自动触发多文件下载；一个小节过长仍需PDF。范围下拉复用SearchFilterSelect材质与交互。

导出到独立白底阅读版：标题、正文、来源网址；不包含导航、外观菜单、背景图、侧栏和推荐。不是网站玻璃背景的截图。PDF走浏览器打印，用户选择另存为PDF。PNG使用动态import的html-to-image 1.11.13，只有点击导出PNG才加载，不调用外部转换服务。图片/字体可按原资源URL加载。

保留静态代码、表格、SVG和数学公式；外部PDF/画布以提示与原文件链接代替，交互控件不导出。Mermaid在导出时用原始源码单独渲染浅色图，不依赖滚动懒加载；保留SVG内部style/ID/marker引用，避免箭头和ID限定样式失效。图表渲染失败会中止并提示，而非静默导出缺图。随后等待字体/图片，20秒超时则提示失败。PNG固定1倍像素比，单张高度超过14000 CSS px提示选择小节/PDF，避免超大canvas缩放截断。跨域资源可能因CORS导致失败，不能保证所有浏览器和图片来源兼容。
