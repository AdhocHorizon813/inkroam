# 阅读音乐

## 2026-10-25 追加：独立外观与双向形变

本节覆盖下文“借用 nav 通道”和全屏淡入的旧实现描述。代码已更新，仍未测试或部署。用户随后报告缩回时横向拉伸，已将父子 scale 补偿替换为真实宽高/位置动画；当前版本不缩放文字与控件字形。

- **显示 → 音乐材质 / 音乐模糊**：独立的液态玻璃、亚克力、云母与 0–48px 模糊。小面板、底部入口、全屏共用音乐通道，与导航分离。默认设置启用时，浅色液态玻璃/14px、深色云母/12px；禁用默认后可手动调整。老用户首次迁移继承原导航值，此后分别保存。
- **全屏往返**：同一面板从菜单位置展开到视口、反向缩回，展开520ms、缩回380ms，使用 `--ease-settle`。直接动画面板宽高和位置，内部组暂时绝对定位、按实际像素位置与宽度移动，文本正常排版，不使用非等比 scale。快速反向接续当前几何状态，两个视图分别保留滚动位置；减少动效时直接切换。该方案有短时布局开销，视觉与性能仍待验收。
- **三种播放模式**：顺序 → 单曲 → 随机。随机从其余曲目均匀抽取，避免立即重复；不是全部播放一轮才重复的洗牌袋。上一首优先返回会话历史，跳过已移除条目。模式持久化，历史不跨刷新保存；不因此预加载音频。

状态为 `musicMaterial/musicBlur`、`data-music-material`、`--music-blur`，复用材料配方，不再借导航状态。随机偏好 `shuffle` 存入原音乐偏好，兼容旧 `repeat` 字段。

## 2026-10-25 八项交互扩展（实现已写，待验收）

本节优先于下方初版说明。按用户要求，本轮未运行测试、类型检查、构建或浏览器验收；未提交部署。

- **高度与信息动效**：内容自然高度由 ResizeObserver 测量，面板 height 使用 420ms `--ease-settle`；歌名和说明以曲目 ID 做短距离位移与淡入淡出，封面交叉淡化。减少动效时即时完成。开合仍复用阅读外观面板的裁剪与位移。
- **平滑进度**：播放器可见且真实播放时，逐帧读取媒体 currentTime，只更新进度输入框；Vue 的时间文字仍由 timeupdate 更新。隐藏、暂停、缓冲、拖动时停止帧循环，不靠估算时间让进度虚跑。
- **播放意图**：连续切歌有独立 continuing 状态，切换资源时不闪回播放图标；首次加载不提前显示暂停。底部曲名/快捷控制仍须等到首次真实 playing 事件后才出现。
- **封面**：`MusicArtwork.vue` 提供三首内置音乐的原创 SVG 封面和本地歌曲的通用图形。打开“管理列表”后，可为当前曲目“更换封面”或“恢复默认”。导入图片为 JPG/PNG/WebP、最大12MB，中心裁切成不超过960px的正方形并保存到本地 IndexedDB。图片不上传；没有提取音频文件中的 ID3/APIC、艺术家或专辑标签。
- **全屏音乐**：右上角展开按钮进入站内视口全屏，同一音频实例持续播放；桌面双栏、手机单栏，Esc 先退出全屏。它不调用浏览器 Fullscreen API，因此不接管阅读外观中的“显示模式”。背景临时不可交互、焦点限制在音乐视图，退出/卸载恢复。
- **字体与列表**：手机底部“显示”文字与“音乐”同为13px，触控高度保留；列表操作改为左侧名称/数量、右侧导入/管理，窄屏可换行。

## 严格按需加载

- 初始HTML的audio只有`preload="none"`，没有src、source或autoplay。
- 挂载、打开面板、查看曲目、恢复偏好、暂停状态切歌都不设置src、不load、不play。
- `play()`是唯一赋src路径，点击播放后通过`loadMusicForPlay`赋当前MP3路径并播放；播放过程中切歌/用户启动的播放列表正常前进也属于同一播放会话。
- 不预取下一首，不做音频preload link、NuxtLink或后台fetch。音频加入静态部署制品不等于访问页面时下载。
- 路径带Nuxt app.baseURL，支持`/inkroam/`。暂停保留当前已请求资源便于恢复；暂停时选择另一首会释放旧src，新曲等再次播放才加载。
- 浏览器按当前播放需要可能分段请求、缓冲当前文件，并不保证点击后只下载少量字节。失败给出重试提示，不自动重试。

## 交互与外观

左下角音乐入口，右下原有阅读设置不挪动。播放时入口旁有快捷暂停。面板提供三曲列表、上下首、播放暂停、进度、音量和列表/单曲循环；关闭面板继续播放。Esc或点外部收起，Esc恢复触发器焦点。图标为SVG，滑块有标签和数值语义。小屏控制区保留触按面积、安全区和面板高度滚动。

复用`dropdown-surface`及`data-dropdown-material`/`--dropdown-blur`，支持纸媒/现代和明暗偏好。组件限定选择器不作用于html/body，不增加渐变伪高光。开合复用现有`animateArticleTool`的非线性grid裁剪，向上展开/收拢，减少动效即时完成。

本地保存键`inkroam-music-v1`，只保存上次所选曲目、音量和循环方式；默认音量35%。不保存播放许可/播放中状态，刷新不恢复自动播放。偏好不受阅读“默认设置”开关管理。
